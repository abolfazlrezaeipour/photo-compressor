# ⚡ Smart Image Compressor

یک ابزار ساده، سریع و کاملاً آفلاین برای فشرده‌سازی و تبدیل تصاویر با رابط کاربری Dark + Neon Blue.

تمام پردازش تصاویر داخل مرورگر انجام می‌شود و هیچ تصویری به سرور یا سرویس آنلاین ارسال نمی‌شود.

---

## ✨ امکانات

### 🖼️ مدیریت تصویر

- آپلود تصویر از سیستم
- پشتیبانی از Drag & Drop
- نمایش تصویر اصلی
- نمایش تصویر فشرده‌شده
- نمایش ابعاد تصویر
- نمایش فرمت تصویر
- نمایش حجم فایل قبل از فشرده‌سازی
- نمایش حجم فایل بعد از فشرده‌سازی

### 🗜️ حالت‌های فشرده‌سازی

#### Lossless

فشرده‌سازی بدون افت قابل‌توجه کیفیت.

مناسب زمانی که کیفیت تصویر اهمیت بیشتری از کاهش حجم دارد.

#### High Compression

فشرده‌سازی شدیدتر برای کاهش بیشتر حجم فایل.

مناسب برای تصاویر وب و زمانی که حجم فایل اهمیت بیشتری دارد.

#### WebP Conversion

تبدیل تصویر به فرمت WebP برای رسیدن به حجم کمتر با کیفیت مناسب.
